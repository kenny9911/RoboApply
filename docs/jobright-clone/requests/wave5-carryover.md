Rules added at the Wave 5 gate that apply to every later change:
- **SCHEMA-5 push is a precondition for running this tree against a database.** `User.tokensValidAfter` is a new column on `User`, so every default `User` read selects it and fails with P2022 against a database without SCHEMA-5. Push before any `npm run dev`, preview or deploy against the clone Neon branch. Diff: `docs/jobright-clone/schema-diffs/schema5-additive.sql` (1 nullable column, 5 new tables, 8 indexes, 4 foreign keys; no DROP / ALTER COLUMN / RENAME).
- **New tables exist after the push** (code already resolves them with no change): `RAReferralSignal` (invite risk signals; until the push every qualified invite is held, reason `signals_unavailable`), `RATwoFactor`, `RAStudentVerification` (until the push both answer 503 `storage_unavailable`), `RAAdminAuditLog` and `RAJobReview` (no writer yet; see WP-93 items 14–15).
- **Rate limits** `totpCodePerUser`, `totpLoginPerUser`, `studentCodePerUser`, `studentConfirmPerUser` are in `RATE_LIMITS` (`platform/ratelimit/defaults.ts`) and tunable through `RATE_LIMITS_JSON`.
- **Cron wiring now live:** `jobs-maintain` runs `adminHealth` (brand step, before `pruneRateCounters`) and `pruneReferralSignals` (platform step); `job-alerts` runs `visitor-alerts` after `alerts`; the `reminders` runner has a `winback` producer.
- **Extension ATS lists** (`EXTENSION_ATS_TYPES_BY_MARKET`, server `extension/contract.ts`, web `hooks/extension/bridge.ts`): intl = greenhouse, lever, ashby, workday, smartrecruiters, icims, workable, taleo, successfactors; cn = moka, beisen, feishu, dayee. Never list `generic`. These are what the extension *fills*; what a job page *offers* is narrower (integration review, Wave 5 gate): `extensionOffersFill(market, atsType, applyUrl)` (registered with the types in the job-detail registry) requires the brand's own market list, an application URL matching the adapter's manifest patterns (`EXTENSION_ATS_HOST_PATTERNS`, kept equal to the adapters' `hostPatterns` by `extension/test/contractParity.test.ts`), and a type outside `EXTENSION_PER_PAGE_ATS_TYPES` (workday, icims, taleo, successfactors — held back until R4, item 17; web mirror `EXTENSION_PER_PAGE_ATS`). A new adapter host goes into both the adapter and `EXTENSION_ATS_HOST_PATTERNS`.
- **Extension contract** mirrors the server's `personal` protected question type and the four newer `EXTENSION_ERROR_CODES`; the extension classifier marks birth date, age, marital status, 政治面貌, 籍贯, ID numbers and health as `personal` (never drafted).
- **Fake Prisma** (`server/src/test/fakePrisma.ts`) now stores `Prisma.DbNull` / `Prisma.JsonNull` as `null`, like the database. Clearing a `Json?` column must write `Prisma.DbNull`, never a literal `null` (Prisma 7 rejects it).
