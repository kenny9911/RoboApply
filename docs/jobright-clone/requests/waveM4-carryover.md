The only network use was read-only GET requests to the documented public board APIs: 1,958 by bundle MKT-4S (recorded in `scripts/board-seeds/report-2026-10-11.json`) and 4 at the gate, one per spot-checked seed entry (`greenhouse/chainguard`, `greenhouse/glossier`, `ashby/9fin`, `lever/animocabrands`: each answered under the name and with the posting count the seed states).
