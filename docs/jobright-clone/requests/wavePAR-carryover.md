## Cross-review round (after the gate)

Thirteen findings of the cross-review (seven medium, six low; two pairs describe the same defect) were checked against the code. All were real and all were fixed at the root, each with a test where a test can express it. What a fix left open is carried over above: items 7a, 7b and 16a, Owner item 1 (the optional override change) and decisions 25a and 25b.

- **Posting age (two findings, one fix).** The feed's 120-day floor cut employer-board and bank rows that ingest never expires by date. `ageFloorSql` applies the floor to aggregator rows and the user's own imports only; the last refill window runs to the end of the list; the session-less preview reads the whole list when its first window cannot fill the request. `NO_AGE_FLOOR_BOARDS` (`feed/sourceLine.ts`) is held equal to ingest's `NO_DATE_EXPIRY_BOARDS` by a test. `verifyFeed --check` (no date condition) no longer counts a row the feed's age floor would hide.
- **A bank row needs a posting page, on the read side too.** `heldBankBoards` / `bankListable` / `bankListableWhere` (`feed/sourceLine.ts`): every feed statement (`SqlScope.heldBanks`), similar jobs, the alerts' Prisma source and cards, Ready to apply and the public-page predicate (`seo/scope.ts`) leave out a bank row whose bank has no template; `applyLinkOf`, the job page and the apply click hand out no link for it. Tests that list bank rows now run with the two templates set (`BANK_PAGES_ENV` in `feed/testkit.ts`).
- **One GoApply model override no longer stops RoboApply.** `assertAssistantModel` (`platform/startup.ts`) refuses the production boot only for the deployment's primary brand (the default brand when served, else the one brand served); a failure of another brand is an error line and that brand's Assistant is unavailable. New boot line for a bare `CN_LLM_MODEL` with no `CN_LLM_PROVIDER` (`cnDefaultModelHasNoRoute`); the rule is stated in `.env.example` and `deploy/cn/cn.env.example`.
- **Cross-border consent follows an own provider that is abroad.** `ownStackLeavesMainland`: GoApply's own bucket off mainland object storage, or its own plane on LiveKit Cloud, now asks for `pipl_cross_border` (catalog, sign-up, onboarding, disclosures, the free-tools notice, which moved to the catalog's predicate).
