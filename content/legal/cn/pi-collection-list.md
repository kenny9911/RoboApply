# 个人信息收集清单

> **草稿（DRAFT）**：以下按产品功能列出收集的信息，正式文本由律师审核（OPS-C）。版本：{{version}}。

| 功能 | 收集的信息 | 目的 | 是否必需 |
| --- | --- | --- | --- |
| 注册与登录 | 手机号或邮箱、微信标识（使用微信登录时） | 创建和登录账户 | 必需 |
| 简历 | 你上传或填写的简历内容 | 生成和修改简历、填写网申表格 | 使用该功能时必需 |
| 个人资料 | 教育经历、实习与工作经历、求职意向 | 准备求职材料、为你排序职位（开启个性化推荐时） | 可选 |
| 敏感信息 | 照片、健康信息、证件信息（仅在你主动填写并单独同意时） | 只用于填写你选择的表格 | 可选 |
| 职位操作 | 浏览、收藏、隐藏、投递记录 | 记录你的求职进度 | 使用该功能时必需 |
| 面试练习 | 你的回答文字；开启录音时的录音和文字记录；另行同意录制视频时的摄像头画面 | 生成练习反馈；保存的录音和视频供你回看 | 使用该功能时必需；录音和视频可选，各自单独同意 |
| 求职助手 | 你发送的消息；开启记忆时你说过的偏好 | 回答你的问题 | 使用该功能时必需 |
| 产品使用事件 | 页面访问和功能使用事件（事件名称、页面路径、发生时间）；匿名访客标识（Cookie `ra_anon`），注册后与账户关联 | 改进产品、排查问题、了解功能使用情况 | 必需；保存 13 个月后删除 |
| 免费工具（未登录） | 从你上传的简历文件中读取的文字和生成的结果；24 小时有效的必要 Cookie `ra_tool_visitor` | 生成检查结果，让同一浏览器再次打开结果 | 使用该功能时必需；24 小时后删除 |
| 职位提醒（未登录） | 邮箱地址和你选择的筛选条件 | 发送职位提醒 | 使用该功能时必需 |
| 辅导申请 | 姓名、邮箱和留言（仅在你单独同意后发送给你选择的独立教练） | 让教练回复你的申请 | 可选 |
| 登录设备 | 账户、浏览器和系统的哈希值，以及浏览器和系统名称 | 在新设备登录时提醒你 | 必需；自该设备最后一次登录起 90 天后删除 |

保存期限见《隐私政策》。
